# Enablement Operations

These agents help sales and revenue teams onboard, train, certify, and coach
people more consistently.

| Agent | What it does |
|---|---|
| [New Hire Readiness Agent](revops-new-hire-readiness/SKILL.md) | Tracks onboarding and ramp progress for new hires. |
| [Certification Tracking Agent](revops-certification-tracking/SKILL.md) | Tracks training completion and escalates overdue certifications. |
| [Coaching Recommendation Agent](revops-coaching-recommendation/SKILL.md) | Turns call insights and performance signals into coaching recommendations. |
| [Playbook Recommendation](revops-playbook-delivery/SKILL.md) | Matches verified deal context to approved, current, access-appropriate playbooks and produces a human-approved delivery preview. |
