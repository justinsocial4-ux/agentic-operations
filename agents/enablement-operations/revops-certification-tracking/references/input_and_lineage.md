# Input and lineage

Accept one structured document with one policy, one complete assignment population receipt, and the exact declared assignment records. Every object rejects unknown keys.

Only stable lowercase IDs and pseudonymous worker/group IDs are allowed. Each assignment binds independently to approved assignment and completion source/version, schema/version, authorization receipt/window, observation receipt, customer rule, certification ID, due rule, recipient roles, and retention rule. The helper rejects undeclared, duplicate, stale, future, unauthorized, or mismatched records.
