# Input and lineage

Accept one structured document with one policy, one complete population receipt, and the exact declared records. Every object rejects unknown keys.

Only stable lowercase IDs and pseudonymous subject/coach IDs are allowed. Each record binds to one approved source/version, schema/version, authorization receipt, rule, observation timestamp, later capture timestamp, allowed recipient roles, retention rule, and exact evidence lanes. The helper rejects undeclared, duplicate, stale, future, unauthorized, or mismatched records.
