# Action boundaries

The output is evidence for an authorized human review. It cannot create or improve coaching, evaluate a worker, infer skill or intent, rank peers, recommend a manager conversation, or support a performance or employment decision.

Do not message, alert, route, schedule, assign, escalate, write a system, contact a customer, change a deal, monitor adoption, or measure outcomes. `coaching_authorized`, `worker_judgment_authorized`, and `action_authorized` are always false.
