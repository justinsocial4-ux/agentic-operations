# Output Template

1. Preflight: policy/catalog versions, cutoff, deal/rep/workspace, sources, channel.
2. Context: stable field IDs, values, provenance, evidence labels, unknowns.
3. Catalog: content ID/version, approved/active/access/superseded state, exclusion.
4. Match: candidate, exact criteria, priority, ambiguity, result.
5. Risks: untrusted text, inferred context, stale/access/privacy gaps, unsupported claims.
6. Preview: exact content/deal/rep/channel, approver, recheck rule, `NO WRITE / NO SEND`.
