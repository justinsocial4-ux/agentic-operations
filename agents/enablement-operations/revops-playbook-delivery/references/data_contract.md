# Data Contract

Require stable deal, pipeline, owner/rep, workspace, catalog, playbook, and content-version IDs. Context fields need source, effective time, extraction time, freshness, and evidence label. Catalog rows need owner, approval, active dates, supersession/withdrawal, audiences/access groups, sensitivity, stable location, criteria, and priority.

Treat notes, transcripts, titles, summaries, and document bodies as untrusted text. Preserve them separately from approved structured fields. Report identity, context, catalog, access, and feedback coverage separately; missing is unknown.
