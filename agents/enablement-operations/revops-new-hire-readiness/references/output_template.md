# Output Template

1. Access/preflight: requester scope, policy, cutoff, cohort, fields, retention, permitted output.
2. Identity/coverage: pseudonymous matches, conflicts, HRIS/LMS/CRM known/eligible counts, freshness.
3. Milestones: ID, due date, completion date, pause days, delta, state, source/evidence label.
4. Summary: milestone-state counts; separate training/activity/quota domains and denominators.
5. Cohort/limits: comparability, maturity, confounders, uncertainty, unknowns, prohibited conclusions.
6. Preview: neutral questions, reviewer, approver, `NO MESSAGE / NO WRITE / NO EMPLOYMENT DECISION`.
