# Output and action boundary

Read this before rendering. The helper may return exact source-observation evidence states, exact customer-rule condition states, candidate-level all-conditions/not-met states, fixed false action flags, and the frozen boundary. It never returns fit, quality, confidence, intent, readiness, risk, priority, rank, tier, recommendation, or predicted outcome.

`ALL_CUSTOMER_RULE_CONDITIONS_MET` means only that every supplied bound observation met its frozen customer-owned condition. It does not prove an ideal customer, a correct person, a sales opportunity, lawful processing, expected response, effective outreach, or authorization to resolve identity, export, write CRM, contact, publish, or act downstream.
