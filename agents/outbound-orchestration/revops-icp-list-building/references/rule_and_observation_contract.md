# Rule and observation contract

Read this before evaluating evidence. Each frozen rule binds one source version, schema version, field definition, value kind, unit, optional denominator definition, observation window, authorization window, exact operator, threshold values, declared candidate population, and unique approval/source/definition/population/completeness/privacy/documentation receipts.

Numeric rules use exactly one canonical nonnegative decimal threshold and `lt`, `lte`, `eq`, `ne`, `gte`, or `gt`. Code rules use one or more opaque `source-code-*` values and `in` or `not-in`. Never translate ordinary prose into a code, infer related categories, normalize a title, widen a range, or reuse a rule outside its source, version, definition, window, or population.
