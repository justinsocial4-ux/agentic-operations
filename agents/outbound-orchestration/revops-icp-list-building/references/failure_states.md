# Failure states

Read this before resolving incomplete evidence. Apply precedence: `UNAUTHORIZED`, `SUPPRESSED`, `EVIDENCE_CONFLICT`, `EVIDENCE_MISSING`, then `SOURCE_OBSERVATION_EVIDENCE_NOT_MATCHED`. Never let a condition-met row erase an unresolved row.

Reject unknown keys, duplicate IDs or receipts, incomplete populations, extra candidates, missing candidate-rule pairs, invalid timestamps, future or out-of-window observations, expired policy/rule/authorization windows, incompatible value kinds, unbound sources or definitions, noncanonical decimals, ordinary prose codes, direct identity fields, or missing prohibited-use controls. Corrected evidence creates a new frozen review.
