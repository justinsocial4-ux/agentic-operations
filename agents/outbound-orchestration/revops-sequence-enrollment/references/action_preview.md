# Action Preview

The skill produces analysis only. The preview must include masked contact ID, proposed sequence ID/name, library/policy versions, workspace/team, owner, matched rules, blockers, approver, expiration/recheck time, and exact proposed system action.

Immediately before any separately authorized execution, recheck suppression, do-not-contact, bounce, owner, active enrollment, cooldown, frequency, sequence active state, and library version. A changed value voids the preview.

Never auto-unenroll, bulk-enroll, send, or write CRM fields. Do not include full email, unnecessary title/activity history, or private compliance evidence in broad reports.
