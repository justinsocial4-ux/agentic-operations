# Output Template

1. Preflight: policy/library versions, cutoff, workspace/team, population, identity and evidence coverage.
2. Eligibility: rule, source value, pass/fail/unknown, blocker.
3. Mappings: masked contact, source value, mapping version, category, limitation.
4. Matches: sequence ID, active state, dimensions, priority, result, recommendation state.
5. Gaps: missing/conflicting/stale evidence, privacy limits, excluded contacts.
6. Preview: exact proposed action, owner, named approver, recheck requirement, `NO WRITE / NO SEND`.
