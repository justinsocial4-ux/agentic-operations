# Meeting Attribution Guide

Read this before reporting meetings or opportunities from outbound.

## Evidence order

1. Explicit platform or CRM link from reply/touch to meeting/opportunity.
2. Deterministic campaign/member/source ID link.
3. Heuristic candidate association using contact/account and time window.
4. Unknown.

Only levels 1 and 2 should be labeled linked. Level 3 is associated, not attributed causally.

## Heuristic sensitivity

If the user approves a window analysis, compare candidate counts at multiple windows such as 7, 14, and 21 days. Report overlap, multiple-candidate ambiguity, and other concurrent touches. Do not pick the earliest opportunity and silently declare one-touch causality.

## Output fields

- evidence level;
- touch/reply ID;
- meeting/opportunity ID;
- time difference;
- competing touches or candidates;
- association rule and version;
- review status.

Do not report a meeting-rate benchmark as customer truth. Measure the customer's explicit-link coverage first.
