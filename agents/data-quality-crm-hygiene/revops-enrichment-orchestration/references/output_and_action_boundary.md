# Output and action boundary

The only route and review states are:

- `CUSTOMER_ROUTE_EVIDENCE_MATCHED`
- `CUSTOMER_ROUTE_EVIDENCE_NOT_MATCHED`
- `EVIDENCE_MISSING`
- `EVIDENCE_CONFLICT`
- `SUPPRESSED`
- `UNAUTHORIZED`

Never add provider rankings, accuracy, confidence, quality, coverage, value selection, recommendations, forecasts, or compliance prose. Enrichment, spend, provider-call, CRM-write, outreach, downstream-decision, and publication flags are always false.
