# Output Contract

Return the helper's one deterministic JSON document byte for byte. It contains the review type/state, policy receipt, declared and source-population receipts, observation receipts, comparison receipts, numeric receipts, and fixed boundary.

The first byte is `{`; the last byte is the helper's newline after `}`. Add no prose, fence, heading, table, calculation, interpretation, correction, or second rendering. Every numeric fact appears only in its helper-owned receipt.
