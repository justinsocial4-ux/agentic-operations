# Privacy And Security

Use pseudonymous quote, account, opportunity, owner-role, line, item, rule, process, and receipt IDs. Reject names, emails, phones, addresses, contacts, titles, messages, free text, activity, buying-committee data, protected traits, and seller performance, quota, compensation, ranking, or coaching fields.

Never execute supplied expressions. Python warns that `eval()` executes arbitrary code and that untrusted input creates security vulnerabilities: https://docs.python.org/3/library/functions.html#eval

Customer privacy, legal, security, accessibility, finance, and system owners govern purpose, access, retention, deletion, correction, residency, and audit controls.
