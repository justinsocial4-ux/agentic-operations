# Configuration Rules

Accept only closed-schema customer rules: exact item requirement, exact item exclusion, item quantity comparison, or numeric fact comparison. Each rule needs a stable ID, precedence, neutral observation label, reviewer role, exact scope, and typed operator/value semantics.

Never use arbitrary expressions, `eval`, code, regex, fuzzy matching, firmographic inference, historical-win inference, ranking, or a default rule. Preserve missing facts, incompatible semantics, and equal-precedence label conflicts for human review.
