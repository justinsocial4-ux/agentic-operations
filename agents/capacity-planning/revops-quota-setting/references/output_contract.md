# Output Contract

Return exact JSON bytes from `render_review_output`, ending at `}` with no trailing whitespace. Add no headings, Markdown, commentary, duplicated numbers, summaries, or corrections.

The document contains one policy receipt with stable review, notice, correction-path, appeal-path, and formula receipt IDs, plus sorted scenario receipts. Each scenario contains source authorization-window lineage, an exact territory-population pseudonymization receipt, one input receipt with every submitted numeric fact once, one calculation receipt with every derived numeric fact once, and opaque territory receipts sorted by ID.

All decimals are strings. `HUMAN_REVIEW_REQUIRED` means only that arithmetic completed and action remains unauthorized. It does not mean approved, fair, achievable, valid for compensation, or likely to occur.
