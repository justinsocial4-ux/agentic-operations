# Output Contract

Return exact JSON bytes from `render_review_output`. Add no headings, Markdown, commentary, duplicated numbers, summaries, or corrections.

The document contains one policy receipt with review, notice, appeal, and formula approvals, plus sorted scenario receipts. Each scenario contains source authorization-window lineage, one input receipt with every submitted numeric fact once, one calculation receipt with every derived numeric fact once, and anonymous territory receipts sorted by ID.

All decimals are strings. `HUMAN_REVIEW_REQUIRED` means only that arithmetic completed and action remains unauthorized. It does not mean approved, fair, achievable, valid for compensation, or likely to occur.
