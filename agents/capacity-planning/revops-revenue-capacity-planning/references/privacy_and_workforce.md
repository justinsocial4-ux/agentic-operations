# Privacy and Workforce Boundary

Use anonymous aggregate scenario variables only. A capacity unit may be labeled with a stable abstract code such as `capacity-unit-a`; it must not identify a person, job title, protected class, team member, manager, account owner, candidate, or employee cohort.

Reject direct identifiers, quasi-identifiers, free text, worker activity, quota, attainment, compensation, performance, ranking, coaching, departure, attrition, ramp, retention, absence, schedule, or protected-trait data.

The skill never selects, ranks, evaluates, recommends, or acts on people. It never decides hiring, firing, replacement, promotion, compensation, quota, territory, workload, scheduling, or recruiting. Every result requires a separate human-controlled review using lawful, approved information outside this skill.

Read-only access is not automatically safe. Sensitive inputs can still create harmful decisions even when no system is modified. Minimize the data before calculation and reject unnecessary worker data.
