# Segment Analysis

Predeclare categories/bands before viewing outcomes. Calculate binary win rate as won / (won + lost). Report won/lost/other, total outcomes, the explicit won-plus-lost denominator, rate, absolute percentage-point difference, Wilson interval, field coverage, and missing bucket. Keep other/unresolved outcomes visible but out of that binary denominator.

Do not create post-hoc quartiles/deciles and then claim confirmation. Significance requires a named test, valid assumptions, predeclared comparisons, multiple-comparison correction, and prospective decision rule. Interval overlap is not that test.
