# ICP And Market Strategy

These agents help teams understand who they should sell to, which segments are
working, and how large the opportunity is.

| Agent | What it does |
|---|---|
| [ICP Development Agent](revops-icp-development/SKILL.md) | Builds an ideal customer profile from won/lost deal patterns. |
| [Segment Performance Agent](revops-segment-performance/SKILL.md) | Compares revenue performance across customer segments. |
| [TAM/SAM Sizing Agent](revops-tam-sam-sizing/SKILL.md) | Estimates market size and reachable opportunity by segment. |
