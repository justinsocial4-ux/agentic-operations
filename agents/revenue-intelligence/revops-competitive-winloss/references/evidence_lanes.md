# Evidence Lanes

Keep these lanes independent:

- `crm_outcome`: an exact customer/platform outcome code.
- `crm_competitor`: an exact customer-recorded competitor code.
- `crm_reason`: an exact customer-recorded reason code.
- `buyer_interview_code`: an exact code assigned under the approved interview method.
- `call_annotation_code`: an exact code assigned under the approved annotation method.
- `public_observation`: an exact code for an observed public-source event.

Never use one lane to fill or validate another. A code records what that source says under that map. It does not prove cause, intent, truth, sentiment, head-to-head competition, strategy, availability, future behavior, or business impact.
