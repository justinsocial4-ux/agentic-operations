# Episode Metrics

```text
episode_days = exit_or_cutoff - entered_at
dwell_ratio = episode_days / approved_comparable_benchmark_days
coverage = deals_with_required_history / eligible_deals
```

Name calendar or business-day clock, timezone, cutoff, cohort, statistic, and benchmark window. A zero/missing benchmark makes the ratio unknown. Compare the same stage definition and comparable cohort. Do not collapse repeated visits unless policy requests accumulated stage time.

An extended or rapid episode is a policy-defined timing observation—not cause, risk, motive, or outcome.
