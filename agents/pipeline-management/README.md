# Pipeline Management

These agents audit opportunity health, stage movement, forecast readiness, and deal governance.

| Agent | What it does |
|---|---|
| [Deal Evidence Review Agent](revops-deal-intelligence/SKILL.md) | Reviews frozen deal evidence and returns exact, unranked review reasons without probability, risk, forecast, coaching, or CRM actions. |
| [Revenue Forecast Agent](revops-forecast/SKILL.md) | Separates CRM category rollups, submitted forecasts, weighted expectations, scenarios, closed-won amounts, and backtest evidence under an approved forecast policy. |
| [Pipeline Health Monitoring Agent](revops-pipeline-health/SKILL.md) | Audits fields, buyer activity, stage age, stalls, and evidence coverage with tested health rules. |
| [Stage Progression Audit](revops-stage-progression/SKILL.md) | Audits dated stage episodes for policy-defined regressions, skips, re-entry, and dwell without inventing motive or forecast impact. |
