# Output Contract

Return one deterministic JSON response containing gate, status, policy/population receipt, per-deal independent current-state/stage/date/activity/amount lanes, exact review reasons, unranked review IDs, prohibited conclusions, action state, and final boundary.

The helper renderer is the only response author. Do not add an introduction, table, recap, recommendation, calculation, correction, or second artifact.

Canonical artifact paths inside the response map requested views to fields in the single JSON object; they do not authorize duplicate prose or files.
