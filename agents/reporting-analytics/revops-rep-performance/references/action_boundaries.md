# Action Boundaries

The review is evidence only. It never authorizes or recommends:

- worker ranking, scoring, labeling, monitoring, investigation, coaching, mentoring, recognition, or comparison;
- hiring, firing, promotion, pay, benefits, discipline, performance plans, leave, schedules, quota, territory, assignment, or access changes;
- customer contact, deal movement, forecast changes, CRM writes, task creation, alerts, messages, emails, Slack posts, or downstream agent decisions;
- causal claims, predictions, targets, benchmarks, confidence, health, risk, adequacy, effort, skill, intent, morale, or personal explanations.

If the user asks for any prohibited action, keep the input unresolved or return the exact helper evidence receipt. Do not soften a prohibition into “consider,” “watch,” “focus,” or “review this worker.”

The only permitted next step is an authorized human review of the evidence receipt under the customer's policy, with no action authorized by the skill.
