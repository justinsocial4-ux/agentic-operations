# Reporting And Analytics

These agents help keep reporting pipelines trustworthy.

| Agent | What it does |
|---|---|
| [ELT Pipeline Monitoring Agent](revops-elt-pipeline-monitoring/SKILL.md) | Monitors ELT pipelines for failure, latency, stale data, and schema drift. |
| [Weekly Revenue Narrative](revops-weekly-revenue-narrative/SKILL.md) | Produces a validated weekly pipeline narrative with exact metric receipts, evidence-backed risk flags, visible unknowns, and preview-before-send controls. |
| [Funnel Conversion Analysis](revops-funnel-conversion/SKILL.md) | Reports ordered reach and mature-window transition evidence with exact helper output, visible pending records, and no invented bottleneck verdict. |
| [Anonymous Rep-Evidence Review](revops-rep-performance/SKILL.md) | Reviews approved anonymous sales-team aggregates with exact suppression and same-basis deltas, without ranking, coaching, or employment action. |
| [Board and Executive Deck Evidence Assembly](revops-board-exec-deck/SKILL.md) | Assembles approved pseudonymous metric, comparison, claim, and slide receipts without inventing narrative, recommendations, or publication approval. |
