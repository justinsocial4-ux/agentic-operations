# Output contract

Return one deterministic JSON document containing policy and allocation-contract receipts, unranked anonymous bucket-credit receipts, per-opportunity evidence/conservation states without repeated numeric values, unresolved evidence, and fixed no-cause/no-ranking/no-decision/no-action boundaries.

All calculated numbers appear only once in their assigned bucket receipts. Render exactly once with helper-defined key and array ordering and the explicit empty terminal line after the closing brace.
