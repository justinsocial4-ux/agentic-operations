# Output and action boundary

Allowed output:

- exact policy and review IDs;
- exact source-bound observation evidence states;
- one supplied observation value per matched observation;
- exact lineage and receipt IDs;
- fixed false action flags.

Forbidden output:

- composite, health, risk, reputation, compliance, priority, confidence, or severity scores;
- cross-provider averages, trends, comparisons, benchmarks, diagnoses, forecasts, or revenue claims;
- remediation instructions, DNS edits, delisting steps, content/list advice, send pauses, alerts, schedules, messages, writes, publications, or workflow actions.

No output is an approval or recommendation.
