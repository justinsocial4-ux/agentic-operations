# Event Marketing

These agents help decide which events are worth attending, sponsoring, or
prioritizing.

| Agent | What it does |
|---|---|
| [Event Selection Agent](revops-event-selection/SKILL.md) | Scores events against ICP fit, expected ROI, competitor presence, and sales opportunity. |
| [Event Orchestration Agent](revops-event-orchestration/SKILL.md) | Turns approved event evidence into a policy-controlled human-review queue without sending or writing records. |
| [Event Analytics & ROI Agent](revops-event-analytics-roi/SKILL.md) | Separates event cost efficiency, configured attribution credit, finance-defined return, and causal incrementality. |
