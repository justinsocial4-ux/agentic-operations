# Output Template

Use six tables:

1. **Preflight/policy:** event/cutoff, policies/models, populations, sources, cost/amount/currency bases, maturity, benchmark/model status, owners.
2. **Population/identity:** registered, attended, cancelled, no-show, staff, excluded, duplicate, known/eligible, coverage, conflicts.
3. **Attribution/outcomes:** pseudonymous opportunity, state, maturity, CRM amount basis, credit, credited amount, model, required-setting completeness, missing fields, and evidence label.
4. **Metrics/finance:** actual/preliminary cost, cost ratios, amounts by state, benefit basis, finance return, incremental ROI, status.
5. **Benchmarks/models/risks:** peer policy/count/period/direction/median/percentile, model-card checks, confounders, unavailable claims.
6. **Decision preview:** descriptive result, prospective validation, owner, approver, exact preview, and `NO CRM WRITE / NO BUDGET CHANGE / NO FOLLOW-UP ACTION`.

Never add inferred revenue, confidence, intent, causal source, projected close, or budget-action columns.
