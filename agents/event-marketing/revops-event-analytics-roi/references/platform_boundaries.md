# Platform Boundaries

Salesforce documents configurable campaign-influence models: model records can be assigned manually or by automation, and the Primary Campaign Source model assigns 100% credit. See [Customizable Campaign Influence](https://help.salesforce.com/s/articleView?id=campaigns_influence_customizable_understanding.htm&language=en_US&type=5).

HubSpot lets customers choose attribution data sources, models, and interaction types. Event registration/attendance interactions may require configuration, settings changes trigger reprocessing, and attribution can be sampled for records with many interactions. See [attribution reports](https://knowledge.hubspot.com/reports/create-attribution-reports) and [interaction types](https://knowledge.hubspot.com/reports/select-interaction-types-for-your-attribution-reports).

HubSpot's Marketing Events API keeps registered, attended, cancelled, and no-show states and warns that UI activity totals may differ from participation counters when states repeat. See [Marketing Events API](https://developers.hubspot.com/docs/api-reference/latest/marketing/marketing-events/guide).

These capabilities assign and report credit under configured rules. They do not prove causal lift, recognized revenue, profit, or cash.
