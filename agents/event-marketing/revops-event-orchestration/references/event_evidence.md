# Event Evidence

Preserve each evidence type:

- `REGISTERED`, `ATTENDED`, `CANCELLED`, and `NO_SHOW` are platform states.
- session attendance, booth scan, and dwell time are recorded behaviors with source limitations.
- `STAFF_CONVERSATION_RECORDED` proves only that an approved record says a conversation occurred.
- `EXPLICIT_MEETING_REQUEST` requires a structured, source-linked request under the customer's definition.
- an email reply is distinct from an open or click.

None of these alone proves purchase intent, buyer authority, customer fit, consent, lawful basis, or future conversion. Missing evidence is `UNKNOWN`; it is not no interest.
