# Output Contract

Return one deterministic JSON response containing the gate, status, policy receipt, criterion definitions, event receipts, capacity receipt, final/provisional/review event IDs, prohibited conclusions, action state, and exact boundary.

The helper renderer is the only response author. Do not add an introduction, table, recap, recommendation, calculation, correction, or second artifact. Keep every number inside the single helper response.

Canonical artifact paths inside the response map requested views to fields in the one JSON object; they do not authorize duplicate files or prose.
