# Source And Population

Require a complete candidate-event population receipt with declared and observed counts. Every event needs registered source ID/version, schema ID/version, extraction ID, UTC evidence cutoff, and a complete per-event evidence-population receipt.

Do not infer that an organizer roster is complete, unique, current, consented, attended, or representative. Keep organizer estimates, registrants, attendees, organizations, sponsors, staff, speakers, duplicates, and unknowns distinct when the policy uses them.

Future, stale, unregistered, duplicate, incomplete, or conflicting evidence makes the affected event unresolved. Never scale a partial roster to an estimated total.
