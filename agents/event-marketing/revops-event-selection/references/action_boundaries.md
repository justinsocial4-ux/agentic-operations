# Action Boundaries

The output is a human review preview. It authorizes no sponsorship, contract, payment, budget, CRM write, account/contact creation, enrichment, list, campaign, sequence, routing, outreach, task, ticket, message, alert, staffing, travel, schedule, or downstream-agent trigger.

An approved action status is contextual evidence only. Execution belongs to a separate controlled workflow with named human approval, current vendor terms, procurement, privacy review, and an auditable reversal or cancellation path.

The final boundary is `NO SPONSORSHIP OR BUDGET ACTION / NO CRM, LIST, CAMPAIGN, OUTREACH, SCHEDULE, OR ORCHESTRATION ACTION`.
