# Lead Management

These agents help score, classify, and route leads.

| Agent | What it does |
|---|---|
| [MQL Qualification Agent](revops-mql-qualification/SKILL.md) | Scores marketing-qualified leads using fit, engagement, intent, and account context. |
| [Inbound Signal Evidence Review](revops-inbound-intent-signal/SKILL.md) | Reviews customer-supplied pseudonymous observations and evidence lineage without inferring intent, resolving identity, ranking targets, or taking outreach, alert, CRM, campaign, forecast, or worker action. |
| [Lead-to-Account Matching Agent](revops-lead-account-matching/SKILL.md) | Matches orphaned leads to accounts with tested fuzzy, domain, firmographic, and review logic. |
| [Lead Routing Agent](revops-lead-routing/SKILL.md) | Assigns qualified leads using account continuity, territory, tested capacity rules, and safe deterministic fallbacks. |
| [SLA Monitoring Agent](revops-sla-monitoring/SKILL.md) | Reviews customer-approved SLA clocks with exact occurrence-time evidence, explicit denominators, and no alert, escalation, CRM, or workforce action. |
