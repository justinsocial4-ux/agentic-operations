# Action boundaries

The receipt authorizes no inference and no action. Never use it to identify a visitor, infer buying intent, score or rank an account, prioritize a rep queue, select a contact, draft outreach, send an alert, create a task, write CRM data, trigger advertising or nurture, change a forecast, monitor a worker, or set compensation.

A human may review evidence outside this skill under separate authority. That separate decision must not be represented as an output or recommendation from this skill.
