# Verification sources

- ICO, Direct marketing guidance and “Collect information and generate leads,” updated April 2026: behavioral profiling requires fairness, transparency, lawful basis, accuracy/minimization, objection handling, and third-party due diligence.
- Google Analytics Help, “Regional data collection”: GA4 discards IP addresses before they are logged.
- Salesforce Developer Documentation, “Get Object Metadata” and GraphQL query guidance: schema and access are metadata-, version-, and permission-specific.
- NIST AI RMF Playbook: define operational limits and evaluate validity/reliability, privacy, security, bias/fairness, transparency, and affected-party feedback.

These sources justify the boundary; they do not certify any customer's implementation or authorize marketing.
