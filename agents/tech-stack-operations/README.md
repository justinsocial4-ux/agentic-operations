# Tech Stack Operations

These agents help teams manage SaaS systems, permissions, integrations, vendors,
and license evidence.

| Agent | What it does |
|---|---|
| [Integration Health Agent](revops-integration-health/SKILL.md) | Checks API connections, sync health, failures, and data freshness. |
| [Tool Utilization Evidence Agent](revops-tool-adoption/SKILL.md) | Reconciles entitlements, identities, approved activity, matched windows, and cost context without inventing waste, value, renewal, or consolidation verdicts. |
| [Permission Audit Agent](revops-permission-audit/SKILL.md) | Compares complete pseudonymous access evidence with approved rules without compliance verdicts or access actions. |
| [Vendor Performance Agent](revops-vendor-performance/SKILL.md) | Reviews contract, service, support, adoption, cost, commitment, and security evidence without inventing a master vendor score. |
