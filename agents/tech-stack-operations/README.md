# Tech Stack Operations

These agents help teams manage SaaS systems, permissions, integrations, vendors,
and license waste.

| Agent | What it does |
|---|---|
| [Integration Health Agent](revops-integration-health/SKILL.md) | Checks API connections, sync health, failures, and data freshness. |
| [Tool Adoption Agent](revops-tool-adoption/SKILL.md) | Finds underused licenses and tool consolidation opportunities. |
| [Permission Audit Agent](revops-permission-audit/SKILL.md) | Flags risky permissions, inactive users, and audit gaps. |
| [Vendor Performance Agent](revops-vendor-performance/SKILL.md) | Scores vendors on SLA performance, support quality, adoption, and renewal risk. |
