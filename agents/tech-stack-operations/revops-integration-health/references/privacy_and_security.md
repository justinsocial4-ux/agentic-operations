# Privacy and security

- Reject OAuth tokens, API keys, passwords, webhook URLs, secrets, direct endpoints, hostnames, tenant names, direct person or company identity, raw logs, free text, message bodies, and secret-bearing errors.
- Use stable pseudonymous integration, system, source, contract, lane, and receipt IDs.
- Require source authorization and pseudonymization receipts plus customer security/privacy review.
- Do not claim GDPR, SOC 2, security, privacy, or regulatory compliance. Governance receipts document review, not compliance.
