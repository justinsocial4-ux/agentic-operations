## Supported conclusions

These sources show that platforms expose different audit/usage reports, permissions, identity handling, lags, event definitions, and product availability. They support source-specific evidence and aggregate-first privacy controls—not universal login targets, cross-tool event scores, or renewal decisions.

Slack describes Audit Logs as an Enterprise audit/security interface and notes that event JSON varies. Microsoft usage reports conceal identities by default and recommend least privilege. Atlassian audit events require admin event-reading scope and have rate limits. Salesforce login/event data requires specific permissions/products and may represent shared system users.

## Quarantined inherited claims

Do not repeat inherited license-waste percentages, market sizes, savings, price/discount benchmarks, app counts, API rate limits, tool feature claims, platform plan claims, statistical significance, or confidence percentages without current primary evidence tied to the exact question.
