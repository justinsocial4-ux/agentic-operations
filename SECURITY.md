# Security And Privacy

This repository is a public library of agent specifications. It should contain
workflow designs and examples only.

## Do Not Commit

- real CRM exports
- customer names or customer emails
- API keys or OAuth tokens
- private Google Drive links
- internal company documents
- generated reports containing private data

## Before Publishing

Run a repository scan for secrets and private data. Treat any real customer data
as a blocker for public release.

## Reporting A Security Issue

Do not open a public issue with private data. Contact the maintainer privately.
