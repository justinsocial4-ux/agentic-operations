# Gong public contract pin

`official-openapi-v2.json` is the exact credential-free public artifact fetched from the URL and date in `openapi-review-v1.json`. Its hash, reviewed read operation IDs, and approved host-set hash are bound in `config/connector_security_v1.json`. The generated loopback server in the artifact is explicitly rejected. No transport or live/account validation occurs in Phase 0.
